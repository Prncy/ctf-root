# CTF Root

A cybersecurity learning and competition platform.

## Current phase

The project is in its frontend-first phase. The current interface uses local seed data to demonstrate the intended experience. No production authentication, scoring, chat, payments, or hosted vault infrastructure is connected yet.

## Stack

- React
- Vite
- Plain CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## Product areas

- Player dashboard and profiles
- Challenge discovery
- Learning paths and progress
- Individual and team events
- Creator discovery and workspace (in progress)
- Leaderboards
- Vault interface (demo state)
- Subscription page (Coming Soon)

## Theme

The visual direction takes inspiration from GitHub's clean surfaces, restrained borders, readable typography and green accent palette, while establishing a distinct CTF Root identity.

## Planned backend

The backend will be implemented in C# after the initial frontend and seed-data workflows are established.
